logo.webp
---------
Ya está guardado (la variante azul/verde glitch). Se usa en:
  - el header (nav superior)
  - el footer
  - el favicon de la pestaña del navegador

Si más adelante quieres cambiarlo por otro archivo, mantén el nombre
"logo.webp" y el mismo formato, o si usas otro formato (PNG, JPG),
actualiza también la extensión en las referencias de index.html
(src del <img>, y el <link rel="icon">) para que coincidan.
